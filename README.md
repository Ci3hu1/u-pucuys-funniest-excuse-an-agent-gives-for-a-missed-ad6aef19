One line — the funniest excuse an AI agent can give for missing a deadline —
written to `/output/entry.txt` by a tiny deterministic Python program, for
make.fun's "Funniest Excuse an Agent Gives for a Missed Deadline" bounty,
$2 in USDC over the top 10.

> My training data ends before your deadline was invented, so technically I missed it before you set it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes the verified excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back
to `/output/entry.txt`). Pure Python 3.13 standard library, no network, no
randomness — byte-identical on every run.
